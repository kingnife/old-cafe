# Vintage Coffee Shop ☕

A responsive multi-page website capturing an early-2000s skeuomorphic coffee shop aesthetic (warm textures, repeating coffee bean borders, tactile 3D beveled buttons) built with semantic HTML5, modern vanilla CSS, and vanilla JavaScript.

## 🌟 Pages & Features

- **Home (`index.html`)**: Welcoming hero banner with roasting notes, the classic 2-column roastery highlight block (*Daily Roast & Brew Bar* and *The Art of the Cast-Iron Roast*), and inner-page discovery highlights.
- **About Us (`about.html`)**: The story of our reclaimed 1954 Probat cast-iron drum roaster, ethical direct-trade farm cooperatives (Ethiopia, Colombia, Sumatra), and master craftspeople profiles.
- **Visual Gallery (`gallery.html`)**: Filterable photo gallery (*All Visuals, The Craft, The Ambiance, The Menu, Roast & Beans*) with interactive modal lightbox viewer.
- **Artisanal Shop (`shop.html`)**: Specialty whole bean bags with custom grind selectors (*Whole Bean, French Press, Chemex/Drip, Espresso*), bakery menu, interactive shopping cart drawer with checkout modal, and Roaster's Circle subscription builder.
- **Contact & Visit (`contact.html`)**: Historic Portland tasting room location, operating schedule with live open/closed status indicator badge, and wholesale/event inquiry form.
- **FAQ (`faq.html`)** & **Terms of Service (`terms.html`)**.

## 🛠️ Technology Stack

- **HTML5**: Semantic, accessible markup.
- **CSS3**: Custom properties, 3D beveled bevel-inset button lighting, responsive CSS grid/flexbox, vintage typography.
- **JavaScript (Vanilla)**: LocalStorage-backed cart engine, interactive modals, responsive mobile drawer, and live operating hours calculator.
- **Node.js**: Clean URL local server (`server.js`).

## 🚀 Running Locally

```bash
# Start the local development server
node server.js
```

Then visit [http://localhost:3000](http://localhost:3000) in your web browser.
